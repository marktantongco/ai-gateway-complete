Configuration Tutorial

Configuration File Description

All configuration files are stored in the configs/ directory. Main configuration files include:

config.json Required

Main configuration file containing API Key, port, model provider and other core settings (auto-created after saving configuration)

provider_pools.json Required

Provider pool configuration for multi-account round-robin and failover (auto-created after saving node)

plugins.json Optional

Plugin configuration for enabling or disabling system plugins

pwd Optional

Admin login password file, default password is admin123

Main Configuration Details (config.json)

Basic Settings

Parameter Type Default Description
REQUIRED_API_KEY string - API Key required to access this service
SERVER_PORT number 3000 Service listening port
HOST string 0.0.0.0 Service listening address
MODEL_PROVIDER string - Default model provider

Proxy Settings

Parameter Type Description
PROXY_URL string Proxy address, supports HTTP, HTTPS, SOCKS5
PROXY_ENABLED_PROVIDERS array List of providers with proxy enabled

Service Governance

Parameter Type Default Description
REQUEST_MAX_RETRIES number 3 Max retry count
REQUEST_BASE_DELAY number 1000 Retry base delay (milliseconds)
CREDENTIAL_SWITCH_MAX_RETRIES number 5 Max bad credential switch retries
MAX_ERROR_COUNT number 10 Max provider error count, marked unhealthy when exceeded
WARMUP_TARGET number 0 Number of nodes to auto-refresh on system startup
REFRESH_CONCURRENCY_PER_PROVIDER number 1 Refresh concurrency per provider

Logs Settings

Parameter Type Description
LOG_ENABLED boolean Enable Logs
LOG_OUTPUT_MODE string Logs output mode (all/console/file/none)
PROMPT_LOG_MODE string Prompt logs mode: none (off), console, file

Configuration Example

{
    "REQUIRED_API_KEY": "your-api-key",
    "SERVER_PORT": 3000,
    "HOST": "0.0.0.0",
    "MODEL_PROVIDER": "gemini-cli-oauth,claude-kiro-oauth",
    "PROXY_URL": "http://127.0.0.1:7890",
    "PROXY_ENABLED_PROVIDERS": ["gemini-cli-oauth", "claude-kiro-oauth"],
    "REQUEST_MAX_RETRIES": 3,
    "MAX_ERROR_COUNT": 10,
    "WARMUP_TARGET": 5,
    "LOG_ENABLED": true,
    "LOG_OUTPUT_MODE": "all"
}

Provider Pool Configuration (provider_pools.json)

Provider pool is used to configure multiple accounts for load balancing and failover. Each provider type can have multiple account nodes configured.

Node Configuration Parameters

Parameter Type Description
uuid string Node unique identifier, auto-generated
name string Node custom name
oauthCredsFilePath string OAuth credential file path
checkHealth boolean Whether to enable health check
checkModel string Model used for health check
notSupportedModels array List of unsupported models for this node
disabled boolean Whether to disable this node

Configuration Example

{
    "gemini-cli-oauth": [
        {
            "uuid": "gemini-account-1",
            "name": "Gemini Account 1",
            "oauthCredsFilePath": "configs/gemini/oauth_creds_1.json",
            "checkHealth": true,
            "checkModel": "gemini-3-flash-preview"
        }
    ],
    "claude-kiro-oauth": [
        {
            "uuid": "kiro-account-1",
            "name": "Kiro Account 1",
            "oauthCredsFilePath": "configs/kiro/kiro-auth-token.json",
            "checkHealth": true
        }
    ]
}

Fallback Degradation Configuration

When all accounts of a provider type are unavailable, automatically switch to a configured backup provider.

Cross-type Fallback Chain

Configure providerFallbackChain in config.json to specify backup types for each provider type:

{
    "providerFallbackChain": {
        "gemini-cli-oauth": ["gemini-antigravity"],
        "gemini-antigravity": ["gemini-cli-oauth"],
        "claude-kiro-oauth": ["claude-custom"],
        "claude-custom": ["claude-kiro-oauth"]
    }
}

Cross-protocol Model Mapping

When the primary provider is unavailable, map specific models to providers of other protocols:

{
    "modelFallbackMapping": {
        "gemini-claude-opus-4-5-thinking": {
            "targetProviderType": "claude-kiro-oauth",
            "targetModel": "claude-opus-4-5"
        }
    }
}
